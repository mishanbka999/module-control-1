## Завдання 1. Основи Dart: класи та колекції

**Мета:** Реалізувати модель бібліотеки з використанням об'єктно-орієнтованого програмування.

У програмі реалізовано:

- Абстрактний клас `LibraryItem`.
- Клас `Book` для представлення книг.
- Клас `Magazine` для представлення журналів.
- Клас `Library` для керування колекцією.
- Метод `addItem()` для додавання елементів.
- Метод `findByYear()` для пошуку за роком.
- Властивість `allDescriptions` для отримання описів.
- Метод `findOldest()` для пошуку найстарішого елемента.

**Результат:** Програма додає книги та журнали, виводить їхні описи, здійснює пошук за роком і визначає найстаріший елемент. Передбачено обробку порожньої бібліотеки.

## Завдання 2. Власний StatelessWidget

**Мета:** Створити повторно використовуваний віджет `RatingBadge`.

Віджет приймає числове значення рейтингу та необов'язковий текстовий підпис.

Колір зірки залежить від рейтингу:

- Від 4.0 до 5.0 — зелений.
- Від 2.5 до значення менше 4.0 — оранжевий.
- Менше 2.5 — червоний.

**Результат:** Створено екран, який демонструє три рейтинги: 4.7, 3.2 та 1.2. Значення відображаються з точністю до одного знака після коми.

## Завдання 3. State Management та навігація

**Мета:** Реалізувати керування локальним станом та передачу даних між екранами.

Створено два екрани:

**HomeScreen:**
- Відображає значення лічильника.
- Містить кнопку збільшення значення на одиницю.
- Використовує `setState()` для оновлення інтерфейсу.
- Відкриває екран деталей через `Navigator.push()`.

**DetailScreen:**
- Отримує значення лічильника через конструктор.
- Відображає отримане значення.
- Повертає користувача через `Navigator.pop()`.

**Результат:** Після повернення з екрана деталей значення лічильника зберігається.

## Завдання 4. Асинхронне програмування

**Мета:** Ознайомитися з використанням `Future`, `Stream`, `async`, `await` та `async*`.

Створено клас `WeatherService`, який містить два методи:

**fetchCurrentWeather(String city)**

Імітує отримання поточної погоди із затримкою дві секунди. Повертає назву міста, температуру та погодні умови. Якщо назва міста порожня, генерує помилку `ArgumentError`.

**temperatureUpdates({int times = 5})**

Генерує потік випадкових значень температури з інтервалом одна секунда. Після заданої кількості оновлень потік завершується.

**Результат:** Реалізовано асинхронне отримання погоди, послідовне оновлення температури та обробку помилок через `try-catch`.

## Інструкція запуску

1. Встановити Flutter SDK та Android Studio.
2. Завантажити репозиторій на комп'ютер.
3. Відкрити папку проєкту в Android Studio.
4. Виконати команду:
flutter pub get


5. Запустити емулятор або підключити пристрій.
6. Виконати:
flutter run


7. У головному меню вибрати потрібне завдання.

Результати завдань 1 і 4 виводяться в консоль Run. Завдання 2 і 3 демонструються в графічному інтерфейсі.
